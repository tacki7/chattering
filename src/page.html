MODEL

モデルの中身

ロール系（各スタンド）

4Hi は BUR–WR–WR–BUR の 4 質量、6Hi は IMR を加えた 6 質量の直列バネ–質量系。上下端はハウジング剛性 kh で固定端に、ロール間は接触剛性で結合。板は WR 間のバネ ks = −∂P/∂h₂ として作用し、固有振動数は det(K − ω²M) = 0 から求める（教科書の式 (8.35) 相当）。減衰は要素ごとに c = 2ζ√(k·mred)。

ロールバイト

P = w · l · Qp · (k̄ − σ̄), l = √(R′·Δh), Hill の Qp = 1.08 + 1.79 r μ √(1−r) √(R′/h₁) − 1.02 r。R′ は Hitchcock の扁平化。先進率は Bland–Ford の中立角から。流動応力 k = (2/√3)·K·(ε₀+ε)ⁿ。

スタンド間の連成

張力: dσi/dt = (E/L)(vin,i+1 − vout,i)。出側速度 vout = vR(1+f)、入側速度は質量流一定 vinh₁ = vouth₂ + κ l ḣ₂。板厚は L/v の遅れで次スタンドに到達（ライブ計算のみ）。

自励のしくみ

ギャップが閉じると入側速度が落ち、後方張力が積分的に下がって荷重が上がる。荷重の変化はギャップ変位に対して 90° 遅れ、速度に同相の力（負の減衰）になる。負の減衰は速度 v と E/L に比例し、ω² に反比例するので、上下逆位相の低次モード（100–200 Hz）が最初に不安定化する。構造減衰 ζ・ハウジング剛性・スタンド間距離を上げると臨界速度が上がる。

20Hi クラスタ（ゼンジミア）

1 スタンドのみ選択可。各半分の WR・1 次中間ロール×2・2 次中間ロール×3・バッキングベアリング×4 を、荷重経路に沿った直列 4 質量（WR / IMR1 / IMR2 / BB）に集約し、モノブロックハウジングに固定。WR は小径（約 70 mm）で扁平化・接触長が小さく、小径ゆえ中立点を保つには大きめの摩擦係数が要る。WR のオフセット力は無効（1 次中間ロール対に挟まれるため）。

ハウジングの伸び変形（任意）

上側の支持を圧下系剛性 ksd → クロスヘッド質量 mH → 支柱伸び剛性 kpost の直列に分ける。ksd は ksd·kpost/(ksd+kpost) = kh となるよう自動導出し、静剛性（ミル剛性）は変えずにハウジング伸びモード（既定で ≈ 200 Hz）を追加する。

水平自由度（全ロール）

各ロールに圧延方向の変位 x を追加（チョック支持剛性 kx／kxI／kxB、ロール間は接触の接線剛性 kt と傾斜接触の幾何剛性 −P/(Ra+Rb) で結合）。WR に働く水平力は前後張力差 ½w(σfh₂ − σbh₁)、バイト合力 λ·l·P/R′（トルク反力、入側向き）、オフセット力 ΔP·e/(RW + RB) の変動分。逆に WR の水平速度はバイトの並進として入側・出側の板速度に加わり、張力→荷重に戻る。

駆動系のねじり振動（任意）

各スタンドを電動機側慣性 JM（減速機・ピニオン込み、ロール軸換算）–スピンドル（ねじり剛性 C・減衰・がた Δφ）–上下 WR 慣性 JW の 3 慣性系で表す（教科書 §9.4.3 の離散系 (9.31)–(9.33)、図 9.28・9.30）。電動機は速度 PI（図 9.31）で駆動。圧延トルク G = λ·l·P + ½(σbh₁ − σfh₂)·w·R が WR の負荷トルクになり、WR の角速度変動はロール周速として先進率・張力の経路に入る。ねじり固有振動数は既定値で約 20 Hz（上下逆相）／21 Hz（電動機–WR 同相）。

両端リール（単スタンド／リバースミル）

ペイオフ／テンションリールは速度ループ付き駆動（帯域 fv）に張力 PI（帯域 ft）が速度指令を補正する構成。リール〜スタンド間の板が E/L の積分器として働き、単スタンドでもスタンド間張力と同じ負の減衰機構が現れる。コイル慣性 J と速度ループの剛性でリール〜板の共振（数 Hz〜20 Hz）が決まる。

限界

AGC・張力制御は無視（チャタリング帯域より十分遅い）。摩擦係数の速度依存、油膜、ロール偏心、ハウジングの多次元モードは含まない。減衰比 ζ は最も不確かで、臨界速度を実機に合わせる調整代。

対象モード
色

「対象モード」で垂直（上下ギャップ・ロール相対・ハウジング伸び）／水平／ねじりを選ぶと、その種類のモードだけで最も不安定な固有値を取って判別する（臨界速度一覧・No.3×No.4 マップも同じ。対象モードが無い点は灰色）。色 = 連成系の最不安定固有値の実部 Re λ（1/s）。赤 = 成長（チャタリング）、青 = 減衰。白線 = 安定限界、◇ = 現在の運転点。線形化モデルなので板厚の伝搬遅れは含まない。「全縦軸」は 6 種類の縦軸を一括計算して横並びに表示（色スケール共通、解像度は単一の約 7 割）。「スタンド別」は要素減衰比 ζ（共通）に加えて、摩擦係数をスタンドごと（No.1〜n の μ）、張力を区間ごと（入側・1–2・…・出側の σ）、圧下率をスタンドごと（出側板厚を変化、次スタンドの入側板厚も連動）に個別に変化させたマップをスタンド数分並べる。4 スタンド以上では圧下率段の下に別の行を設け、速度を現状 +200 / +400 / +600 m/min に固定した No.3×No.4 圧下率マップ 3 枚（最終出側板厚一定、実線 = No.3・No.4 だけの配分替え）を横に並べ、その下に速度ごとの比較表を表示する（安定な配分が無い速度でも表示）。マップ内のラベルは領域ごとの主な周波数（中央値）と主スタンド。「モード帯」の色分けは、安定＝薄い青、不安定域はその最不安定モードの種類で垂直振動（上下ギャップ開閉・ロール相対・ハウジング伸び）＝オレンジ、水平振動＝緑、ねじり振動（駆動系）＝紫、その他（張力・リール・高次）＝灰。細かい種別はホバーとラベルで確認。金色の点線 = 近似式（負の減衰の釣り合い、解説 §5 式 (5.4)）による臨界速度のスタンド最小値。隣スタンドの応答を無視するため数値計算より低速側に出る。

HOW TO READ

安定性マップの詳細説明

何を計算しているか

格子点ごとに、その運転条件で動作点（各スタンドの荷重・先進率・板バネ剛性）を求め直し、全スタンドのロール系＋スタンド間張力（＋リール、WR 水平）を含む非線形状態方程式を動作点まわりで数値的に線形化して行列 A を作る。A の固有値 λ = Re λ ± j·2πf のうち、振動モード（f ≥ 5 Hz）で実部が最大のものを採る。Re λ > 0 なら微小な擾乱が eRe λ·t で成長する＝チャタリングが自励する条件。

色と線

赤の濃さは成長率（1/s）。例えば +20 /s なら板厚偏差が 10 倍になるまで ln10/20 ≈ 0.12 s。青は減衰率で、濃いほど早く収まる。白線（Re λ = 0 の等高線）が安定限界で、横軸方向にこの線を読めば各条件の臨界速度になる。◇ は今のサイドバー設定の位置。線の右側（高速側）が不安定領域。

ホバー

各格子でのモード周波数と主スタンド（ギャップ振幅が最大のスタンド）を表示する。3 次オクターブ帯（100–200 Hz）と 5 次オクターブ帯（500–700 Hz）のどちらが先に立つかを、周波数から判別できる。

縦軸の選び方

要素減衰比 ζ: 実機で最も不確かな量。実測の臨界速度が分かっていれば、白線がそれを通る ζ を選ぶのが校正の手順。
摩擦係数倍率: 全スタンドの μ を一斉にスケール。潤滑状態（乳化・油膜）の変化に対応。μ が下がると荷重が下がり、板バネ剛性も下がるため限界が動く。
張力倍率: スタンド間張力の設定値を一斉にスケール。
スタンド間距離 L: 張力剛性 E/L を通じて負の減衰の大きさを決める。短いほど不利。
ハウジング剛性: ミル剛性。高いほどギャップ開閉モードの周波数が上がり、負の減衰（∝ 1/ω²）が効きにくくなる。
板幅: 荷重と張力による力の両方に比例。

前提と限界

線形化なので「小振幅の擾乱が育つかどうか」だけを判定する。振幅が育ったあとの飽和や破断はライブ計算で見る。板厚の伝搬遅れ（L/v）は含めていないため、再生型（前スタンドの板厚ムラが次スタンドで増幅される）チャタリングの周波数選択性はマップには現れない。AGC・張力制御の遅い動特性も無視。数値は既定パラメータ（特に ζ）に依存する目安であり、実機データによる校正が前提。

計算コスト

格子は 28×20 で 560 点。各点で行列サイズ N（5 スタンド 4Hi・水平あり: 64）の固有値問題を解く。裏側の Web Worker で数秒。解像度「細」は 4 倍かかる。パラメータを変えると自動で再計算する。
